# 表情工坊 · GIF Studio

一个精致、丝滑、全本地的**表情包生成器**。拖入视频自动转成 GIF，拖入图片自动缩放压缩，内置网友常用的尺寸、滤镜（变糊 / 包浆 / 锐化…）与参数，界面遵循 Apple 式的高级简洁设计。

> **品牌**：表情工坊（GIF Studio）· 蓝紫渐变 + 白色播放键的应用图标，支持 favicon、Apple Touch Icon 与 PWA 安装。

无需安装、无需联网、无构建步骤——**打开就能用**，所有处理都在浏览器本地完成（文件不会上传）。

## 快速开始

1. 打开 `index.html`（或单文件 `dist/表情工坊.html`）。
2. 把视频或图片**拖进**舞台，或点击「选择文件」。
3. 视频会自动开始转 GIF；图片会自动缩放。右侧面板可实时调参，滤镜即时预览。
4. 完成后点击「下载」保存，或「复制」到剪贴板。

> 也可以一次拖入**多张图片**，会批量压缩并进入底部历史条。

## 滤镜说明

- **变糊**：高斯式模糊，模拟手抖 / 被压缩。
- **包浆**：降分辨率 + 低色深 + 噪点 + 灰绿褪色，复刻“网上传烂了的老表情包”质感。
- **锐化**：反锐化蒙版（unsharp mask），让边缘更清晰。
- 复古 / 黑白 / 高饱和：经典色调滤镜。
- 所有滤镜都有「强度」滑块，实时所见即所得。

## 参数速查（网友常用）

- **迷你图标 / 头像**：`25×25`、`32×32`、`50×50`、`64×64`、`128×128`（正方形）。
- **微信表情**：`240×240 · 8–10 fps · 64–128 色`，建议控制在 **≤ 1MB**。
- **大表情 / 群聊动图**：`320×320` 或 `480×480`。
- **横版梗图**：`640×360`（16:9）。
- **体积优化**：帧率越低、颜色数越少，文件越小；`速度 2×` 可进一步减小体积。

> 想存自己的尺寸？调好宽高后点「＋ 保存尺寸」，命名即存为预设；悬停预设上的 × 可删除。

## 部署到 GitHub Pages

1. 推送到 GitHub 仓库。
2. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`（或 `master`），目录选 `/ (root)`。
3. 保存后即可通过 `https://用户名.github.io/仓库名/` 访问。

## 技术说明

- **视频转 GIF**：`<video>` 逐帧 seek → `canvas` 合成（适配 + 文字 + 滤镜）→ [gifenc](https://github.com/mattdesl/gifenc) 做色量量化（NeuQuant）与 LZW 编码，主线程分帧让出渲染，进度实时可见、可取消。
- **图片缩放**：`createImageBitmap` 解码 → `canvas` 重绘 → `toBlob` 输出 PNG / JPEG / WebP。
- **滤镜**：像素级处理（模糊 / 锐化 / 包浆 / 色调），预览走 GPU 的 `ctx.filter` 近似、输出走精确算法。
- **透明支持**：`完整`（contain）适配时使用 RGBA4444 + 透明索引，留白区域为透明底，适合做贴纸。
- **零依赖、零构建**：不依赖任何 CDN，离线可用；仅需现代浏览器（Chrome / Edge / Safari / Firefox 最新版）。
